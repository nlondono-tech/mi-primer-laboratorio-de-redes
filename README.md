Mi primer laboratorio de redes

Objetivo

Aprender los conceptos básicos de las redes informáticas y documentar mi progreso.

Conceptos básicos

* Dirección IP: identifica un dispositivo en una red.
* DNS: traduce nombres de dominio a direcciones IP.
* DHCP: asigna automáticamente la configuración de red.
* Router: conecta redes y dirige el tráfico.

Prácticas pendientes

* [ ]	Consultar la configuración de red de mi computador.
* [ ]	Aprender a utilizar el comando ipconfig.
* [ ]	Investigar cómo funciona DNS.
* [ ]	Dibujar una red doméstica.

Mi aprendizaje

Este repositorio forma parte de mi formación inicial en redes informáticas y ciberseguridad.

Prácticas realizadas

1. Comando ipconfig

Objetivo: consultar la configuración de red del computador.

Resultado: identifiqué los campos de dirección IPv4, máscara de subred y puerta de enlace predeterminada.

2. Prueba de conexión interna

Comando utilizado: ping 127.0.0.1

Resultado: recibí cuatro respuestas y consulté las estadísticas de los paquetes.

Aprendizaje: esta prueba comprueba la comunicación interna de la computadora.

3. Consulta DNS

Comando utilizado: nslookup example.com

Resultado: obtuve una respuesta no autoritativa.

Aprendizaje: DNS permite consultar qué dirección IP corresponde a un nombre de dominio.
