Mi primer laboratorio de redes

Objetivo

Aprender los conceptos básicos de las redes informáticas y documentar mi progreso.

Conceptos básicos

* Dirección IP: identifica un dispositivo en una red.
* DNS: traduce nombres de dominio a direcciones IP.
* DHCP: asigna automáticamente la configuración de red.
* Router: conecta redes y dirige el tráfico.
